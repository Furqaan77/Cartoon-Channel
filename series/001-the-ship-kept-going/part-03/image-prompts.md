# Part 3, "Oscar": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). **KEEP won the Part 2 vote**, and these prompts are written for it.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt (e.g. **Refs:** you-wet = `reference-images/you-wet.png`). **Always attach `you.png` as well whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-03/images/` under the name shown in **Save as**. Type just the name (e.g. `01a`), without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, the HUD and the vote buttons.
5. Movement is added in the edit.

**This part's look:**
- **The sea (3:08–4:31 a.m.):** the darkest part of the series, starlight only, blue-black. The golden-brown seaweed in 07 is the one warm thing out there.
- **The jacket:** open in 01a and 02b. From 04a on, **he has zipped it up to the chin**, and it stays zipped for the rest of the part (a story action, allowed by the character lock).
- **Flashback (09):** warm amber candlelight.
- **Ship interior (13–16):** cold fluorescent corridors, then amber warning lights once the alarm goes off.
- **The return (17–20):** hard white searchlights.
- **HUD:** TIME 3:08 → 3:20 → 4:31 AM, STRENGTH 85% → 84% → 79% → 70%.

**To make:** 20 images, 2 text cards and 4 reused images (`01b` and `03` are already in `images/`; `10` reuses this part's `01a`; `15` reuses this part's `14`).
