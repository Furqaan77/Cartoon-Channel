# Part 4, "From Behind": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). **SIGNAL won the Part 3 vote**, and these prompts are written for it.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt (e.g. **Refs:** you-wet = `reference-images/you-wet.png`). **Always attach `you.png` as well whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-04/images/` under the name shown in **Save as**. Type just the name (e.g. `02b`), without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, the HUD and the vote buttons.
5. Movement is added in the edit.

**This part's look:**
- **Rescue (02–05):** blue-gray pre-dawn, hard white searchlight, an orange rescue boat. The jacket is still zipped to the chin.
- **From shot 07 on:** the ship's medical bay in cold fluorescent white-green. **YOU keeps the soaked yellow jacket on (unzipped again), with a crinkly silver foil blanket over his shoulders.** The yellow stays the brightest thing in every frame.
- **CCTV footage (12–14):** grainy black and white.
- **HUD:** STRENGTH 62% in the water, then no HUD from shot 07.

**To make:** 23 images, 3 text cards and 2 reused images (`01a` is already in `images/`; `01b` is Part 3's `17`, which I copy in once Part 3's images exist).
