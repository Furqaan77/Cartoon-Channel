# Part 5, "The Note" (finale): image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). **TELL won the Part 4 vote**, and these prompts are written for it.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt (e.g. **Refs:** you = `reference-images/you.png`). **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-05/images/` under the name shown in **Save as**. Type just the name (e.g. `07a`), without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text and the phone messages.
5. Movement is added in the edit.

**This part's look:**
- **Medical bay (01–04):** cold fluorescent. YOU is still in the soaked yellow jacket with the foil blanket, as in Part 4.
- **Cozumel and the ferry terminal (05, 11, 13):** bright, harsh sun and turquoise water.
- **The letter's flashbacks (07b–10):** night, warm amber lamp against teal shadow.
- **From the cabin on (06, 15–20):** YOU is dry again, in his normal locked outfit.
- **Galveston (15–16):** flat gray.
- **Home at 2:14 a.m. (17–20):** blue-black, lit only by a phone. The last two shots show him **from behind in the yellow jacket**, the way the killer sees him.

**To make:** 21 images, 1 text card and 2 reused images (`09b` is already in `images/`; `10b` is Part 3's `13`, which I copy in once Part 3's images exist).
