# Part 2, "Done": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). **FLOAT won the Part 1 vote**, and these prompts are written for it.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt (e.g. **Refs:** you-wet = `reference-images/you-wet.png`). **Always attach `you.png` as well whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-02/images/` under the name shown in **Save as**. Type just the name (e.g. `01b`), without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, the HUD and the vote buttons.
5. Movement is added in the edit.

**This part's look:** night sea in navy and teal. After the ship's lights vanish (shot 08), only starlight remains: darker and bluer. The swim alternate world (04) is desaturated in the edit. The flashbacks (11, 16) are warm amber. Deck 5 (15, 17) keeps its orange lamps. The HUD shows TIME 2:14 → 2:59, and STRENGTH 94% → 88% → 85%.

**To make:** 18 images, 5 text cards and 2 reused images (`01a` is already in `images/`; `19b` reuses this part's `09`).
