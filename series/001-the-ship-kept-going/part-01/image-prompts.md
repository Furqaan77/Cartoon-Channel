# Part 1, "Nobody Saw": image prompts

One still image per shot, in the 2D look of the reference reels. Shot numbers and times follow [script.md](script.md).

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt (e.g. **Refs:** you-wet = `reference-images/you-wet.png`).
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image as `part-01/images/NN.png` (e.g. `07a.png`).
4. **Text cards** need no image. Build them in the edit, using the card styles in the reference file. All on-screen text is added in the edit, never by the image model.
5. Movement (push-in, pan, shake) is added in the edit, as in the reference reels. You can also animate a still with image-to-video.

**This part's look:** night sea in navy and teal with sodium-orange ship lights, and the yellow jacket as the brightest thing in frame. The flashback (shots 11–14) is warmer amber. The HUD starts at shot 05 (TIME 2:14 AM · STRENGTH 100%).

**To make:** 21 images and 2 text cards.
