# Season 3, Part 2, "Rule Four": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). Written for **TELL winning**; for LIE, see the swaps at the bottom.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-02/images/` under the name shown in **Save as**. Type just the name, without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, phone screens and the HUD.
5. Movement is added in the edit.

**This part's look:** hard Caribbean morning on the fishing boat; a dim cabin with one porthole; the found jacket in turquoise water. HUD DAYS LEFT appears at "It's Thursday": 3.

**To make:** 13 images, 4 text cards and 3 reused images (I copy the reused ones in).
