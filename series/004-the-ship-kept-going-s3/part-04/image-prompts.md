# Season 3, Part 4, "Him or Me": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). Written for **STAY winning**; for RUN, see the swaps at the bottom.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-04/images/` under the name shown in **Save as**. Type just the name, without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, phone screens and the HUD.
5. Movement is added in the edit.

**This part's look:** hard white noon, a stuffy island police office with a ceiling fan, then sunset on the pier and long blue shade where Doyle waits. HUD DAYS LEFT 2 → 1 (Saturday).

**To make:** 13 images, 3 text cards and 2 reused images (I copy the reused ones in).
