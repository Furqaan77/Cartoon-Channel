# Season 3, Part 1, "No Lights": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md).

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-01/images/` under the name shown in **Save as**. Type just the name, without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, phone screens and the HUD.
5. Movement is added in the edit.

**This part's look:** black sea and starlight, one flashlight beam, then a pink-gold Caribbean dawn on the fishing boat. No HUD in this part; Doyle's deadline doesn't exist yet.

**To make:** 15 images, 2 text cards and 4 reused images (I copy the reused ones in).
