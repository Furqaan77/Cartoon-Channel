# Season 3, Part 3, "Against the Current": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). Written for **QUIET winning**; for POLICE, see the swaps at the bottom.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-03/images/` under the name shown in **Save as**. Type just the name, without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, phone screens and the HUD.
5. Movement is added in the edit.

**This part's look:** hard turquoise morning on Lucía's pier and dive shop; the photo from Puerto Morelos in flat bright daylight; dust in the sun when the car pulls up. HUD DAYS LEFT 2 (Friday).

**To make:** 12 images, 3 text cards and 5 reused images (I copy the reused ones in).
