# Part 3, "It Never Dries": image prompts

One still image per shot, in the house look made darker for horror (see [reference/character-prompts.md](../reference/character-prompts.md)). Shot numbers follow [script.md](script.md). **PULL won Part 2's vote**, so this is the PULL version. The LISTEN image is kept at the bottom for reference.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot, and `you-wet.png` for the copy.**
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-03/images/` under the name shown in **Save as**.
4. All on-screen text, cards, captions and vote buttons are added in the edit, never by the image model.

**This part's look:** blue-black night; the three 1987 flashbacks (06–08) are faded sepia. Small wet footprints glint in the moonlight.

**To make:** 14 images, 1 text card and 1 reused image.
