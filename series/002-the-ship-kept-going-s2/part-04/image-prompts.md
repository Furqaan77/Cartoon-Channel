# Season 2, Part 4, "The Pier": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). Written for **TEST winning**; for TRUST, shot 03 uses `18A.png` from Part 3 instead (no new image needed).

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-04/images/` under the name shown in **Save as**. Type just the name, without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text and the vote buttons.
5. Movement is added in the edit.

**This part's look:** the pier at dusk going to night, then the dive shop under sodium-orange string lights; headlights cut across it white. Agent Kerr's dark gray sedan has tinted windows. The back-seat shot is the only one inside the car.

**To make:** 18 images, 2 text cards and 3 reused images (`08` is already in `images/`; `01` is Part 3's `17`, which I copy in once it exists; `06` reuses this part's `05`).
