# Season 2, Part 2, "The Collar": image prompts

One still image per shot, in the 2D look of the reference reels (playbook §11.1). Shot numbers and times follow [script.md](script.md). Written for **CALL winning**; the GO swap is at the bottom.

**How to use**
1. The reference images are in this part's [reference-images/](reference-images/) folder. Attach the ones listed under **Refs** to each prompt. **Always attach `you.png` whenever YOU is in the shot**, so he stays on-model.
2. Paste each prompt exactly as written. Every prompt is complete, with the style included.
3. Save each image in `part-02/images/` under the name shown in **Save as**. Type just the name, without `.png`.
4. **Text cards** need no image. I build them in the edit, as are all on-screen text, phone messages and the vote buttons.
5. Movement is added in the edit.

**This part's look:** dawn at home in blue-gray; Cancún in harsh, over-bright white sun; the airport bathroom in sickly fluorescent green. The strip of fabric is plain white with tiny unreadable scribbles.

**To make:** 12 images, 3 text cards and 3 reused images (`12` is already in `images/`; `01a` is Part 1's `17` and `15` is this part's `14`, which I copy in once those exist).
