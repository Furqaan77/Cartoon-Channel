## Quality gate
- [ ] Hook ≤ 12 words, has a concrete detail plus a threat or contradiction
- [ ] Hook is said and shown in the first frame
- [ ] A stranger understands it within 15s without earlier parts
- [ ] Previous cliffhanger paid off within the first 20s
- [ ] New information every ≤ 8s, a turn every ≤ 15s
- [ ] False relief comes before the final turn
- [ ] Ends worse than it started
- [ ] Last line is a reveal, threat, or decision, not a summary
- [ ] Loop ledger: ≥ 1 closed, ≥ 1 bigger opened
- [ ] VO word count in range
- [ ] Read-aloud test passed (no stumbles)
